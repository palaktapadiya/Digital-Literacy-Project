## Project Overview

This repository contains my Digital Literacy Portfolio, submitted as part of the CSE0001 course at VIT Bhopal University. The project is based on the scenario of being selected as a **Student Digital Ambassador**, responsible for helping fellow students navigate the digital world safely, professionally, and responsibly.

The portfolio is organised across five tasks, each mapping to one module of the course. All work — including screenshots, written files, email drafts, case studies, and the project report — is documented in this repository.
